# KISAN-MITRA AI 🌱

### AI-Powered Agriculture Assistant

## About the Project
KISAN-MITRA AI is an agriculture assistant designed to help users explore crop recommendations, irrigation guidance, plant disease classification, and farm analytics.

## Features
- **Crop Recommendation:** Recommends crops using soil and environmental inputs.
- **Irrigation Advisor:** Provides rule-based irrigation guidance.
- **Disease Analysis:** Experimentally classifies uploaded tomato leaf images.
- **Farm Analytics:** Displays farm-related charts and sample data.
- **Dashboard:** Offers an overview of the application's features.

## Technologies Used
- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- Joblib
- Pillow
- Matplotlib

## Machine Learning
The crop recommendation model achieved 99.55% accuracy on its held-out test dataset. The experimental disease classification model achieved 43.33% test accuracy. These results do not guarantee real-world performance.

## Limitations
The irrigation advisor uses predefined rules. Some dashboard and analytics information may be sample data. Disease predictions are experimental and should not be treated as confirmed diagnoses.

## Run Locally
Install the required dependencies and run:

`python -m streamlit run app.py`
